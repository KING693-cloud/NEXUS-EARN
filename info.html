NEW DEPOSIT METHOD – BANK TRANSFER

We've moved to a secure manual bank transfer system via PalmPay. No more Paystack – just send money directly and get credited after admin approval.

July 15, 2026
Deposit via PalmPay – What You Need to Know
  • Bank: PalmPay
  • Account Number: 896‑2925‑124
  • Account Name: NEXUS EARN LIMITED(TAIWO) Opay Note
  • On OPay and some banks, it may show as NEXUS(TAIWO) – that's still the correct account.

🔐 Narration Code (IMPORTANT):
  • When you start a deposit, a unique 10‑character alphanumeric code will be generated (e.g., 188EBEDIR).
  • You MUST include this code in the transaction narration/description when sending money.
  • If the code is missing or wrong, the admin will reject your deposit.
  • The code is valid for 15 minutes – after that, it expires and you must start a new deposit session.

📋 After Sending Money:
  • Submit the form on the deposit page with: Amount, Sender Name, Sender Account Number (optional).
  • Admin verifies the narration code and amount, then approves your deposit – your balance is credited exactly the amount you sent (0% fee).
  • You'll see the status in your History page: Pending → Approved / Rejected.

Minimum Deposit: ₦15,000 (so you can start with VIP 1).

FAQs About the New Changes

Quick answers to the most common questions about the new updates.

Why did you change the contract to 365 days?
We listened to our community! A full 1‑year contract gives you longer, more stable returns and aligns with our vision of building a sustainable investment ecosystem. Upgrading resets your timer, so you can always extend your earning period.
How do I deposit with the new bank transfer method?
Go to the Deposit page, copy the PalmPay details (896‑2925‑124, NEXUS EARN LIMITED(TAIWO)), generate your 10‑character narration code, send your amount (min ₦15,000), and submit the form with your sender name. Admin approves within 24 hours.
What happens if I forget the narration code?
The narration code is required for admin to identify your deposit. If you forget it, your deposit will be rejected. Always copy and paste the code into your bank transfer description. You can also copy it from the deposit page.
Why is there a 15‑minute timer on deposits?
The timer ensures that narration codes are unique and time‑bound for security. If the timer runs out, your code expires and you must start a fresh deposit session. This prevents code reuse and protects both users and admins.
Can I withdraw more than once a day?
You can only have one pending withdrawal at a time. If your pending request is from today or yesterday, you cannot submit another until it's approved or rejected. Once it's processed, you can request a new withdrawal immediately.
